This repository contains the complete 4-week project pipeline for the DecodeLabs AI Engineering Internship. It includes four distinct projects that progress from basic logic to model evaluation:

Project 1: Rule-Based AI Chatbot
A pure Python chatbot that processes text inputs continuously using an optimized dictionary lookup instead of linear conditional statements.

Project 2: Data Classification Using AI
A supervised machine learning script using scikit-learn that loads the Iris dataset, applies feature scaling, splits data into training and testing sets, and trains a Logistic Regression classifier.

Project 3: AI Recommendation Logic
An information retrieval script that converts text tags into sparse vectors using a TF-IDF matrix and sorts item recommendations based on their Cosine Similarity score to a user profile.

Project 4: Model Evaluation Metrics
A native matrix auditing script that extracts True Positives, True Negatives, False Positives, and False Negatives using NumPy array comparisons to compute Accuracy, Precision, Recall, and F1-Score from scratch with protection against zero-division errors.
